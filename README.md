# Gold Macro Pulse

A dashboard checking, with real data, whether rising oil prices actually lead to falling
gold prices, plus a same-day gold macro-pressure score and a tested buy-the-dip/sell-the-high
signal.

**Live site:** https://shivangpandya460.github.io/gold-macro-pulse/

- [`index.html`](index.html) — the dashboard: gauges, charts, backtests, the reading log
- [`reasoning.html`](reasoning.html) — the reasoning & methodology: the macro-chain check,
  the full correlation table, the predictive-power test, and how the score is built

Not investment advice. Refreshed on a regular cadence from free public data sources (FRED,
gold-api.com).
